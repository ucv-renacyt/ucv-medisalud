# Medisalud — Encuentro

Propuesta vectorial creada desde cero para este proyecto. Dos formas curvas acompañan un punto central: encuentro entre paciente y profesional, cuidado y una M abierta.

## Archivos

- `medisalud.svg`: símbolo principal, turquesa, azul profundo y acento cálido.
- `medisalud-usuario.svg`: variante para pacientes.
- `medisalud-doctor.svg`: variante azul para médicos.
- `medisalud-admin.svg`: variante violeta para administración.
- `medisalud-monocromo.svg`: versión de una tinta.

Los SVG tienen fondo transparente, no contienen fuentes, imágenes incrustadas, recursos externos ni trazados tomados de los logos anteriores. Los trazados se escribieron directamente para esta propuesta. El PNG de presentación es una vista previa, no el archivo maestro.

Esta descripción documenta el proceso de creación; no constituye un registro de marca ni garantiza exclusividad o ausencia de signos similares. Antes del uso como marca comercial debe comprobarse su disponibilidad. No se incorpora el nombre ni el emblema de la UCV. Las tres aplicaciones usan `medisalud.svg` con la misma paleta principal. También se actualizaron los favicons, los iconos de Android y sus pantallas de arranque. Los archivos con nombres anteriores se conservan con el nuevo diseño para compatibilidad.
